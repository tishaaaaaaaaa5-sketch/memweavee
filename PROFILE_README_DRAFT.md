# Hi, I'm Tisha 👋

I build and evaluate machine-learning systems, with a focus on efficient language models, long-term conversational memory, and practical AI tooling.

## Research interests

- Efficient deep learning: quantization, state-space models, and hardware-aware inference
- LLM systems: memory, retrieval, evaluation, and long-context behavior
- Reproducible empirical research: controlled experiments, ablations, and transparent reporting
- Applied AI engineering: developer tools and security/compliance workflows

## Selected projects

### [Shift-Scan](https://github.com/tishaaaaaaaaa5-sketch/shift-scan)
Research prototype exploring ternary projections and power-of-two decay approximations for Mamba-2 language models. The repository documents accuracy trade-offs and a negative GPU-kernel performance result rather than claiming an unverified speedup.

### [MemWeave](https://github.com/tishaaaaaaaaa5-sketch/memweavee)
Research project on role-aware, budget-constrained memory retention for long-horizon conversations. The current LongMemEval-S result is an aggregate held-out evidence-recall result; independent benchmark validation remains planned.

### [Compliance Assistant](https://github.com/tishaaaaaaaaa5-sketch/COMPLIANCE-ASSISTANT)
A Node.js/Gemini prototype for bounded source-code triage, compliance-oriented Q&A, modernization suggestions, and MCP-based workflows. It is decision support, not a compliance certification.

## How I work

I value matched baselines, clear limitations, reproducible experiments, and publishing negative results alongside positive ones. I aim to distinguish measured evidence from hypotheses and planned work.
