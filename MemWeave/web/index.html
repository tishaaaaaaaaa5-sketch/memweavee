EVIDENCE-CENTRED · BUDGET-AWARE · AUDITABLE

Beyond storing more.
Preserving what matters.

Long conversations contain more information than an active context window can hold. A useful memory system must decide what to retain, recover the right evidence later, and make its decisions inspectable.

MemWeave is a research project studying evidence-aware retention and retrieval under explicit memory budgets. It separates retention, retrieval, context construction, and downstream answering so each stage can be evaluated honestly.
